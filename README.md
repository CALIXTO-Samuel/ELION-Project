# ELION — Site institucional

Site público de apresentação do projeto ELION.

## Estrutura

- `index.html` — conteúdo e estrutura da página.
- `assets/css/style.css` — identidade visual e layout responsivo.
- `assets/js/main.js` — navegação mobile.

## Publicação

O site é estático e pode ser publicado pelo GitHub Pages usando a branch `main` e a pasta `/ (root)`.

No repositório, acesse **Settings → Pages → Build and deployment → Deploy from a branch**, selecione `main` e `/ (root)`, e salve.

## Proteção do projeto

Este repositório contém somente material institucional público. Não adicione credenciais, chaves, dados empresariais, documentação interna ou código-fonte proprietário.

O conteúdo deste repositório não concede licença de reutilização do sistema ELION.
