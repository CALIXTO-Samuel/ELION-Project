# ELION — Site institucional

Site público de apresentação do projeto ELION.

## Páginas
- `index.html` — visão geral, pilares, ecossistema e princípios.
- `original.html` — visão profissional ELION ONE.
- `beta.html` — escopo e funcionamento planejado da ELION BASE BETA.
- `comparativo.html` — diferenças documentadas entre Original e Beta.
- `testes.html` — cenários, comportamentos esperados e validações pendentes.
- `assets/css/style.css` — identidade visual e layout responsivo.
- `assets/js/main.js` — navegação mobile.

## Publicação
O site é estático e pode ser publicado pelo GitHub Pages usando a branch `main` e a pasta `/ (root)`.

No repositório, acesse **Settings → Pages → Build and deployment → Deploy from a branch**, selecione `main` e `/ (root)`, e salve. A publicação precisa ser conferida nas configurações do repositório.

## Como interpretar a página de testes
Os cenários publicados representam requisitos e resultados esperados definidos durante o planejamento. Eles não significam que testes físicos foram executados ou aprovados. As metas atuais de autonomia são de até 30 horas para o ELION ONE e até 16 horas para a BASE BETA; nenhuma delas foi validada. A autonomia dependerá do consumo medido, das cargas essenciais incluídas, da capacidade útil da bateria, das perdas de conversão, da temperatura, do envelhecimento e das margens de segurança. Dimensões, refrigeração, desempenho, compatibilidade, estabilidade e integração também dependem de protótipo e validação técnica.
